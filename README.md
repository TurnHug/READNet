
## Lightweight Condition-Constrained Salient Object Detection Based on Elastic Pixel Difference Convolution

This repository contains the implementation of READNet and its prediction maps.

### Project structure

```text
configs.py          # Training and evaluation configuration
dataset/            # Dataset definitions and data loaders
mobilevit_v3/       # MobileViT-v3 backbone components
train_utils/        # Training utilities and helper functions
model.py             # READNet model definition
train.py             # Training entry point
validation.py        # Validation entry point
test.py              # Test/inference entry point
pre_maps/            # Saved prediction maps
```

### Prediction maps

`pre_maps/` stores 4,551 PNG prediction maps generated by READNet:

- `CSOD10K/` — 2,497 maps
- `WXSOD_real/` — 554 maps
- `WXSOD_sys/` — 1,500 maps
